# 03_pdf_parsing（PDF 解析与元数据提取）

目标：对 Step 02 得到/下载的 PDF 进行结构化解析，抽取标题、摘要、作者、发表日期、关键词、参考文献等，并输出每篇论文的结构化 JSON。

输入：
- Step 02 扩展论文列表中的 PDF（或可下载链接）：
  - 如果你有 URL：在 03 里先下载/缓存
  - 如果你已有本地 PDF：直接读取

工具（建议）：
- `GROBID`：本地 Docker 部署（提取标题/摘要/作者/机构/引用）
- `scipdf_parser`：Python 封装，调用 GROBID 并输出结构化字典

输出（写入 step_results）：
- `*.json`：结构化元数据（标题、摘要、作者列表、发表日期、关键词、参考文献）
