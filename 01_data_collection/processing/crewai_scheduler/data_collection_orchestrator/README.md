# Data Collection Orchestrator (CrewAI)

Minimal runnable CrewAI project for step `01_data_collection`, aligned with the Bright Data MCP runtime in:

`../brightdata_mcp_connector/service`

## Quick start

1. Activate runtime venv from `../runtime/.venv`.
2. Copy `.env.example` to `.env` and fill your API keys.
3. Run:

```powershell
python -m src.data_collection_orchestrator.main
```
